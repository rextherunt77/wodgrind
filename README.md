# WODGrind

Workout timer for coaches that runs in the phone's browser: **count up** (with an optional time cap), **count down**, **EMOM**,
**AMRAP** and **Tabata / intervals**. Big full-screen clock, beeps and voice cues in English and Finnish, and **WOD Code** –
athletes follow the same clock on their own phones (at the ski ergs, the rower, across the gym, or on a TV).

**Open the app:** https://rextherunt77.github.io/wodgrind/ – then *Add to Home Screen*. Works offline after the first visit.

Settings stay on your phone; nothing is sent to this site. WOD Code connects phones directly (WebRTC via public Nostr relays, using
[Trystero](https://github.com/dmotz/trystero), MIT licence).

From the REPGrind family: https://rextherunt77.github.io/repgrind/

Version 0.2.9. This repository holds only the built app; it is published from a private project.
