WODGrind – guide

WODGrind is a workout timer for coaches. It runs in the phone's browser: open it once, then Share → Add to Home Screen. After the first visit it also works without internet (WOD Code needs internet).

Timers

TimerYou setWhat happens
Count uptime cap in minutes (optional)Clock counts up from 0:00. With a cap it stops by itself and says Time cap. Without a cap press Stop twice when the athletes are done; the clock shows the final time.
Count downminutes and secondsPlain countdown with minute calls and Finish at zero.
EMOMtotal minutes, every N minutesA long beep and Round 2, Round 3… at every new interval, short beeps on its last 3 seconds. Every 2 minutes = E2MOM.
AMRAPminutesCounts down. Says halfway, minutes left, one minute, 30 and 10 seconds and Finish.
Tabatawork s, rest s, roundsLong beep = work, double beep = rest, short beeps on the last 3 seconds. Says Last round. Classic Tabata is 20 / 10 × 8.

Every timer starts with a countdown (5 s, change it in Setup) spoken as 5-4-3-2-1. The clock fills the screen and keeps the screen on. Turn the phone sideways for bigger numbers.

  • Pause stops the clock, Resume continues.
  • Stop needs two taps, so a stray hit doesn't end the workout.
  • Colours: yellow numbers = countdown, white = work, orange = last 3 seconds, blue = rest, green = finished.

WOD Code – the clock on the athletes' phones

  1. Coach: WOD Code → Create WOD Code (I'm the coach). A 4-character code appears, also at the top of the screen.
  2. Athletes: open WODGrind → WOD Code, type the code and tap Join. Or send them the invite with Share invite.
  3. Coach picks the timer and presses Start. Every phone shows the same clock to the second and gives the beeps and voice cues in its own language.
  • Pause, resume and stop on the coach's phone go to everyone. Late joiners get the running clock straight away.
  • Each phone runs the clock itself, so a short break in the connection doesn't stop it.
  • A tablet or TV browser can join the same way to show the clock across the gym.
  • Phones connect directly to each other (WebRTC). Free public Nostr relays only help them find each other – the same method as in RepGrind. No accounts, nothing stored on a server. Some strict company or school Wi-Fi networks block this; mobile data works.
  • End WOD Code sends everyone back to their own timer.

Sound

  • Setup → Sound: voice cues (female voice where the phone has one) and beeps can be turned off separately. The voice follows the app language.
  • iPhone: turn off silent mode, and tap the screen once after joining a WOD Code (browsers allow sound only after a tap).
  • Bluetooth speakers work: the phone's sound goes there as usual.
